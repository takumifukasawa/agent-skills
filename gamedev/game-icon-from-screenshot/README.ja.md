# game-icon-from-screenshot

ローカルで動いている Web / canvas ゲームを headless Chromium でスクショし、選んだ要素の周りを切り抜いて正方形の PNG アイコン（既定 512x512）を作るスキルです。手描きの近似ではなく、実際のゲーム画面そのものがアイコンになります。

> このファイルは人間向けの説明です。Claude が実際に読むのは [SKILL.md](./SKILL.md)（英語）で、動作はそちらで決まります。

## こんなときに使う
- 「アイコン作って」「512x512 のアイコン」
- 「実際のゲーム画面をスクショしてアイコンにする」
- アプリアイコン / ストアアイコン / favicon / サムネイルが欲しいとき
- Phaser / PixiJS / Three.js / 素の canvas のゲームが localhost で動いている場合が対象。ゼロからアイコンを描く用途には使いません

## やること
1. ゲームを既知の URL で起動しておく（縦画面ゲームなら縦の viewport を使う）
2. ゲーム固有の設定ファイル（`icon.config.json` か `.cjs`）を書く。中心になるのはページ内で動く 2 つの関数
   - `ready`: ゲームの初期化が済んだかを返す
   - `clip`: 被写体のポーズを決め、HUD を隠し、切り抜く矩形（CSS px）を返す
3. ハーネスを実行する: `node scripts/shoot.cjs icon.config.json public/icon-512.png 512`
4. できた PNG を確認し、ポーズ・切り抜きの詰め具合・viewport を調整して繰り返す
5. 候補が複数あるときは、兄弟スキル `game-store-assets` の選定ページ（Artifact）でユーザーに選んでもらう。アイコンだけの選定（正方形・1 つ選択のグループ 1 つ）にも、ストア画像と一緒の選定にも使える。選択とコメントは Claude が読み取る

ゲーム内部の座標と CSS px のずれ（DPR やレターボックス）は、注入される `window.canvasCssRect(canvas, gx, gy, halfInternalPx)` で吸収できます。

## 前提・必要なもの
- ゲームがローカル URL で動いていること（例: `npm run dev` → `http://localhost:5173`）
- Playwright + Chromium（プロジェクトの `node_modules`、npx キャッシュ、グローバルから自動で探す）
- Pillow（Python）。無ければ初回に自動インストール
- `clip` から被写体を操作・計測できるだけの手がかり（dev 用ハンドル、DOM、グローバル変数など）。何も公開されていなければ、固定矩形を返して静的に切り抜くこともできる

## 注意点
- 重なっている最中ではなく「直前」の瞬間をポーズにすると、動きのあるアイコンになる
- スコアやヒントなどの HUD は隠すか、写らないように切り抜く
- 正方形でない切り抜きは `pad` 色（ゲームの背景色を推奨）で正方形にしてからリサイズされる
- `ready` は最大 20 秒待つ。リロード直後は少し時間がかかることがある
- 物理やリアルタイムのゲームは、ライブのフレームを狙うより `clip` の中で位置を決めて（可能なら一時停止して）決定的にポーズさせる
- 512px だと被写体が小さく弱く見える場合は、ゲームの実際の要素の形・色を PIL で組み直す方法に切り替える（ゼロから描くのとは別物）。ぼかしなど半透明の要素は透明レイヤーに描いて `alpha_composite` しないと、`convert("RGB")` でアルファが落ちて不透明な塊になる

## 同梱ファイル
- `scripts/shoot.cjs` — スクショ → 切り抜き → 正方形化までを行うハーネス本体
- `scripts/resize_square.py` — 画像を pad 色で中央寄せの正方形にして NxN にリサイズする
- `references/hand-composed-icon.md` — 実要素を PIL で組み直すフォールバック手法と、PIL のアルファ / AA / グロー / 軌跡の落とし穴
